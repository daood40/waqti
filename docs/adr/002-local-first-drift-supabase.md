# ADR-002 — Local-first: SQLite (Drift) مصدر الحقيقة + Supabase للمزامنة

**الحالة:** معتمد (التوجيه v2 §25) — التنفيذ: المرحلة 0 (Drift) والمرحلة 4 (Supabase)

## السياق
المنتج يَعِد بعمل كامل دون إنترنت وسرعة استجابة < 100ms، مع مزامنة بين الأجهزة.

## القرار
قاعدة SQLite عبر Drift على الجهاز هي مصدر الحقيقة بنفس مخطط PostgreSQL على Supabase (§27). كل قراءة/كتابة تتم محليًا، والمزامنة عملية خلفية (تصميمها في `docs/SYNC.md`).

## البدائل المرفوضة
- Supabase أولًا مع Cache: يجعل Offline حالة ثانوية هشة ويبطئ كل تفاعل.
- بقاء `shared_preferences`: لا يدعم استعلامات ولا FTS5 ولا حجم بيانات §31.

## النتائج
ترحيل بيانات `waqti.v1` القديمة إلى Drift عند أول تشغيل؛ اختبارات المزامنة (§35) إلزامية قبل تفعيل المرحلة 4.
