# ADR-004 — التكرار بـ RRULE (RFC 5545) + توليد كسول

**الحالة:** معتمد (التوجيه v2 §25، §10) — التنفيذ: المرحلة 1

## السياق
التكرار الحالي 5 أنواع مخصصة لا تغطي "آخر جمعة من الشهر" ولا "كل 3 أيام"، ولا تحمل استثناءات أو شرط نهاية.

## القرار
قاعدة واحدة RRULE في `task_recurrence` مع `recurrence_exceptions`، وتوليد التكرارات **كسولًا عند العرض** — يُخزَّن فقط المكتمل والاستثناءات. تعديل تكرار: "هذا فقط / هذا وما بعده / الكل". أمثلة القواعد في ملحق (د).

## البدائل المرفوضة
- توليد مسبق لكل التكرارات: انفجار صفوف وترحيلات مؤلمة عند تعديل القاعدة.
- إبقاء النموذج المخصص: لا يفي بمتطلبات §10 ويقفل الاستيراد المستقبلي للتقويمات.

## النتائج
محوّل يرحّل الأنواع الخمسة القديمة إلى RRULE مكافئ؛ اختبارات إلزامية تشمل الاستثناءات والمناطق الزمنية والتوقيت الصيفي (§35).
