## 3) الشكاوى المتكررة في المراجعات (ما لم يحلّه المنافسون) — وحلولنا

| المشكلة (تكرارها في المراجعات) | كيف يحلّها وقتي |
|---|---|
| **«خسرت سلسلة 60 يومًا بعد إعادة التثبيت/تحديث النظام»** | نسخة احتياطية محلية تلقائية يومية + زر استعادة، تصدير JSON/CSV بنقرة، وقريبًا مزامنة سحابية |
| **قلق السلسلة (يوم واحد يصفّر كل شيء)** | درجة عادة تهبط تدريجيًا (نموذج Loop) تظهر بجانب السلسلة، إنجاز متأخر يحفظ السلسلة، يوم راحة، لا شاشة «فشل» حمراء |
| **جدار الدفع يظهر بعد الاستثمار في التطبيق** | الحدود معلنة من الشاشة الأولى؛ السجل والإحصاءات والتصدير مجانية دائمًا |
| **تعب التلعيب بعد 4–6 أسابيع** | التلعيب خفيف (أوسمة تقدم لا حيوانات أليفة)، ويمكن تجاهله دون أن يعيق الاستخدام |
| **تخصيص محدود (العادة لا تشبه حياتي)** | كمية/وحدة، فترة يوم، تذكيرات متعددة، تكرار مرن، أيقونة ولون وفئة، إقلاع أو بناء |
| **الإشعارات إمّا مزعجة أو صامتة** | تذكير لكل عادة بأوقات متعددة + ساعات هدوء + لا تذكير لما أُنجز بالفعل + ملخص صباحي/مسائي اختياري |
| **تقويم صغير لا يُقرأ (Streaks)** | شبكة شهرية كبيرة + تقويم كامل + خريطة سنوية |
| **مقفل على منصة واحدة (Streaks/Loop)** | أندرويد، iOS، ويندوز، ويب — كود واحد |
| **تعارض المزامنة (سجلات مكررة)** | تصميم مزامنة بحقل-مستوى LWW موثق في `docs/SYNC.md` قبل بناء الخادم |
| **الترجمة العربية آلية والاتجاه مكسور** | عربي أولًا، RTL أصيل، هجري، قوالب دينية |
| **يطلب حسابًا قبل أي شيء** | زائر بنقرة، لا حساب إلزامي |
| **ثقيل وبطيء عند الفتح** | شاشة تحميل فورية، محلي بالكامل، لا شبكة |
