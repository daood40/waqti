# تحليل المنافسة — «وقتي» مقابل تطبيقات العادات والمهام

المقارنة مع الأكثر انتشارًا في الفئة: **Habitify، Loop Habit Tracker، Streaks،
HabitNow، TickTick، Todoist، Fabulous، Habitica**. الهدف: (1) إغلاق فجوات
المزايا، (2) حلّ مشكلات شائعة لم تحلّها تلك التطبيقات، (3) تثبيت ما يميّزنا.

## 1) فجوات المزايا — وما نفّذناه

| الميزة | موجودة عند المنافسين | وقتي قبل | وقتي الآن |
|---|---|---|---|
| عادات كمية (8 أكواب، 20 صفحة) | Habitify، Loop، HabitNow | ✗ | ✅ هدف يومي + وحدة، كل نقرة تزيد خطوة، بلوغ الهدف = إنجاز |
| يوم راحة لا يكسر السلسلة | Habitify (skip) | ✗ | ✅ حالة «راحة» محايدة لا تُحسب ولا تكسر السلسلة |
| إيقاف عادة مؤقتًا مع حفظ سجلها | Habitify، HabitNow (archive) | ✗ | ✅ إيقاف/استئناف من التفاصيل، تظهر «موقوفة» في القائمة |
| مؤقت تركيز (بومودورو) | TickTick، Forest | ✗ | ✅ 15/25/45/60 دقيقة، يعتمد وقت الانتهاء لا التكّات، يسجل الدقائق ويقترح إنجاز المهمة |
| مكتبة عادات جاهزة | Fabulous، HabitNow | ✗ | ✅ 12 قالبًا عربيًا (فجر، قرآن، ماء، قراءة…) تملأ المحرر بنقرة |
| وقت تذكير لكل عادة | الجميع | ✗ | ✅ اختيار الوقت في المحرر (الجدولة الفعلية على الجهاز في الحزمة التالية) |
| أوسمة متدرجة بشريط تقدم | Habitica، Streaks | جزئي | ✅ 14 وسامًا في 4 أقسام + «هدفك التالي» |
| لوحة «اليوم أولًا» | TickTick، Todoist | ✅ | ✅ + المتأخرات بنقرة واحدة |
| خريطة سنوية حرارية | Loop، Habitify | ✅ | ✅ |
| تصدير/استيراد البيانات | Loop | ✅ | ✅ |
| عربي RTL كامل + هجري | لا أحد يقدّمه جيدًا | جزئي | ✅ التاريخ الهجري في الترويسة، RTL أصيل |

## 2) مشكلات لم يحلّها المنافسون — وحلّنا

1. **قلق السلسلة (Streak anxiety)**: يوم واحد فائت يكسر سلسلة شهور فيهجر المستخدم التطبيق (أكثر شكوى في مراجعات Streaks وHabitify).
   - **حلّنا**: (أ) الإنجاز المتأخر من بطاقة «المتأخرات» **يحفظ السلسلة** (يُحسب إنجازًا بنقاط أقل). (ب) «يوم راحة» للمرض والسفر. (ج) السلسلة تُحسب على المهام المستحقة فعلًا فقط.
2. **الإفراط في العادات ثم الفشل**: التطبيقات تسمح بعشرين عادة يوميًا دون تنبيه.
   - **حلّنا**: الخطة المجانية تبدأ بخمس عادات (حدّ صحي مقصود)، والأوسمة تكافئ الاستمرارية لا الكثرة، والإيقاف المؤقت يبقي الحياة واقعية دون حذف.
3. **الاستخدام بلا هدف واضح**: المستخدم يفتح التطبيق ولا يعرف «ماذا الآن؟».
   - **حلّنا**: «مهام اليوم» أولًا بترتيب الأولوية (عاجل → منخفض)، ثم المتأخرات، ثم بطاقة «هدفك التالي» في الإنجازات.
4. **السوق العربي مُهمَل**: ترجمات آلية، اتجاه نص مكسور، لا تاريخ هجري، لا عادات دينية جاهزة.
   - **حلّنا**: عربي أولًا بخط Tajawal، RTL أصيل، هجري، قوالب (فجر، ورد قرآن، أذكار).
5. **الاحتجاز خلف الاشتراك**: الأساسيات (السجل الكامل، التصدير) مدفوعة عند Habitify/Streaks.
   - **حلّنا**: السجل الكامل والتصدير والإحصاءات مجانية؛ المدفوع = السعة والمزامنة والتخصيص.
6. **البطء وثقل الواجهة وطلب حساب قبل أي شيء**.
   - **حلّنا**: دخول كزائر بنقرة، شاشة تحميل فورية، يعمل بلا إنترنت، بياناتك على جهازك.

## 3) ما يميّزنا (نبقيه ونبني عليه)

- «اليوم أولًا» + المتأخرات بنقرة + إنقاذ السلسلة.
- هوية عربية كاملة (هجري، قوالب، خط) مع إنجليزي كامل.
- مؤقت التركيز مدمج مع العادات (الشعار ساعة إيقاف — الميزة تعزّز العلامة).
- خصوصية: صفر تتبع، صفر إعلانات خارجية.

## 4) التالي في الخارطة (يتطلب بنية تحتية)

| الميزة | التطبيقات | المتطلب |
|---|---|---|
| تذكيرات على الجهاز (إشعارات محلية) | الجميع | حزمة إشعارات + اختبار على جهاز حقيقي |
| مزامنة بين الأجهزة + نسخ سحابي | Habitify، TickTick | قاعدة بيانات + مصادقة (Supabase) |
| ويدجت الشاشة الرئيسية | Streaks، Loop | كود منصة خاص لكل نظام |
| مشاركة/تحدّيات مع الأصدقاء | Habitica | خادم + حسابات |
| دفع حقيقي للباقات | — | RevenueCat + منتجات المتاجر |

## 5) هل يحتاج التطبيق دومين/قاعدة بيانات/استضافة؟

- **الآن (الإطلاق الأول): لا.** التطبيق محلي بالكامل، والويب مستضاف مجانًا على GitHub Pages، والمتاجر تستضيف الحِزم.
- **دومين (اختياري، ~50 ريال/سنة)**: يُحسّن الثقة (waqti.app) ويُستخدم لسياسة الخصوصية والموقع التعريفي؛ GitHub Pages يدعمه مجانًا.
- **قاعدة بيانات + مصادقة (لاحقًا)**: مطلوبة فقط عند تفعيل المزامنة والحسابات الحقيقية. المقترح **Supabase** (الباقة المجانية تكفي آلاف المستخدمين): Postgres + Auth + Realtime، بلا خادم تديره.
- **استضافة خادم**: غير مطلوبة؛ Supabase مُدار بالكامل.
- **الدفع**: RevenueCat (مجاني حتى 2,500$ إيرادات شهريًا) يوحّد Play/App Store.
