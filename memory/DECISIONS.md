## ADR-009 — مفتاح الإيقاف عن بُعد كملف JSON ثابت على GitHub Pages · 2026-09-09 · الحالة: نافذ
القرار: `web/app-config.json` يُجلب عند الإقلاع (مهلة 4 ث)؛ أي فشل = لا حجب.
البدائل: جدول Supabase رُفض لأن الخادم غير مفعّل في بناء الإطلاق؛ Remote Config من Firebase رُفض (لا Firebase).
الأثر: يمكن فرض تحديث أو صيانة بتعديل ملف واحد ودفعه؛ الرابط في `AppLinks.remoteConfig`.
## ADR-008 — حساب حقيقي عبر Supabase Auth + نسخة سحابية بسيطة · 2026-09-04 · الحالة: نافذ
القرار: بريد/كلمة مرور الآن، Google/Apple لاحقًا، نسخة سحابية LWW بسيطة، Sentry بلا PII.
البدائل: Firebase رُفض (SQL وRLS أبسط للحجم)؛ مزامنة لحظية رُفضت (مؤجلة).
الأثر: التطبيق يعمل بلا خادم كزائر؛ الحساب يُفعَّل بالأسرار فقط.
## قرار الإطلاق — كل المزايا مجانية، لا باقات في الواجهة · 2026-09-02 · الحالة: نافذ
القرار: `kLaunchMode=true`؛ شاشة الباقات غير قابلة للوصول (شروط المتاجر: لا محتوى نائب).
