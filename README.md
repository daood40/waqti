# وقتي (Waqti) ⏳

تطبيق Flutter لتتبع المهام والعادات اليومية — عربي/إنجليزي، فاتح/داكن، ويعمل على Android وiOS والويب.

🌐 **جرّبه الآن:** [daood40.github.io/waqti](https://daood40.github.io/waqti/)

> هذا المشروع تحويل كامل واحترافي لنموذج HTML أولي إلى تطبيق Flutter حقيقي، مع حفظ دائم للبيانات وتحسينات جوهرية. النموذج الأصلي محفوظ في `design/waqti_prototype.html`، ونسخة React السابقة مؤرشفة في الفرع `archive/react-version`.

## المزايا

- **مهام اليوم**: بطاقة إنجاز سريع في الرئيسية — أنجز مهام اليوم بنقرة واحدة مع شريط تقدم
- **الجدول الشهري**: شبكة عادات أسبوعية (نافذة 7 أيام) مع تقليب حالة كل يوم بنقرة واحدة: منجز ✓ → متأخر ! → فائت ✕ → فارغ
- **التقويم**: عرض شهري كامل مع ملخص إنجاز كل يوم
- **الإحصائيات**: نسبة الإنجاز، التتابع (Streak)، نقاط الخبرة، أفضل/أضعف عادة، أعمدة أسبوعية، منحنى إنجازات يومي، و**خريطة سنة حرارية** بأسلوب GitHub
- **المهام والعادات**: إنشاء وتعديل وحذف (مع تراجع)، **إعادة ترتيب بالسحب والإفلات**، تصنيفات، أولويات، وتكرار مرن (يومي / أسبوعي / شهري / أيام محددة / مرة واحدة)
- **الإنجازات**: مستويات ونقاط خبرة وأوسمة تُفتح تلقائيًا
- **الإعدادات**: لغة (عربي RTL / إنجليزي)، مظهر فاتح/داكن/**تلقائي يتبع النظام**، إشعارات (تفضيلات)، تصدير/استيراد JSON
- **حساب واشتراك (محاكاة)**: تسجيل دخول محلي، خطة مجانية بحد 5 مهام، وخطة Premium تجريبية
- **بيانات تجريبية**: زر لتحميل عادات نموذجية بسجل واقعي لاستكشاف التطبيق فورًا
- **هوية كاملة**: أيقونة إطلاق مخصصة لكل المنصات (Android Adaptive / iOS / ويب + favicon) واسم معرّب

## تحسينات على النموذج الأصلي

| النموذج الأولي (HTML) | تطبيق Flutter |
|---|---|
| البيانات تُفقد عند إغلاق الصفحة | حفظ دائم عبر `shared_preferences` |
| حالات الإنجاز مفهرسة برقم اليوم فقط (تتكرر في كل الشهور!) | مفهرسة بالتاريخ الكامل `yyyy-MM-dd` |
| حد الخطة المجانية غير مُطبَّق | مُطبَّق فعليًا (5 مهام) مع دعوة للترقية |
| حذف بدون تأكيد | تأكيد + تراجع (Undo) |
| بيانات عشوائية مزروعة | يبدأ نظيفًا ببيانات المستخدم الحقيقية |
| Streak محصور بالشهر الحالي | يمتد عبر حدود الشهور |
| خط عبر CDN | خط Tajawal مضمّن (يعمل دون إنترنت) |

## النشر والتوزيع

### الويب — GitHub Pages

‏`.github/workflows/deploy-pages.yml` يبني نسخة Flutter Web وينشرها على
GitHub Pages **مع كل push** بالمسار `daood40.github.io/waqti/`.
محرّك CanvasKit يُحمَّل من ملفات التطبيق نفسها (لا CDN خارجي)، فيعمل
التطبيق كاملًا دون إنترنت بعد أول زيارة.

الإعداد لمرة واحدة: من إعدادات المستودع **Settings ← Pages ← Source ← GitHub Actions**.

### أندرويد — APK

‏`.github/workflows/build-apk.yml` يفحص الكود (تنسيق + اختبارات) ثم يبني
APK باسم **"وقتي"** مع كل push ويرفعه كـ Artifact:

1. افتح تبويب **Actions** ← آخر تشغيل ناجح لـ **Build Android APK**
2. حمّل **waqti-apk** من قسم Artifacts وثبّت `app-release.apk` على هاتفك
   (فعّل "التثبيت من مصادر غير معروفة")

> النسخة موقّعة بمفتاح تطوير — مناسبة للاستخدام الشخصي والتجربة.
> النشر على Google Play يتطلب مفتاح توقيع Release خاصًا بك.
